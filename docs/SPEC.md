# GiriStair 初期仕様

## 目的

プレイヤー本人が、生大喜利・ネット大喜利の予定、参加記録、大会の結果、考えた回答やお題を残します。観客向けの出演記録や他ユーザーとの交流機能は初期範囲に含めません。

## 5つのタブ

1. **登録** — 生／ネットで入力欄を切り替えます。大会／通常会は開催形式とは独立した項目です。
2. **一覧** — 登録した会を検索・確認・編集します。
3. **戦績** — 大会の結果を振り返ります。結果未記録を敗戦として数えません。
4. **思考** — 現在投稿期間中のネット大喜利と、その会への回答メモを表示します。主催会に向けたお題メモ、会に紐づかないメモも扱います。
5. **設定** — 会場別・参加者別などの集計を補助機能として配置します。

## 会の記録

共通項目はタイトル、主催者、生／ネット、大会／通常会、参加状態（予定・参加済み・キャンセル）、メモです。

- **生大喜利**：開催日、会場、開始・終了時刻、参加者。参加者は1人ずつ入力・追加・削除でき、過去の記録やプレイヤー一覧からも選べます。文章の貼り付け・画像OCRは候補を確認・訂正してから一括追加します。画像の文字認識は端末内で行います。
- **ネット大喜利**：サイトURLと複数の日程。予選1回戦・本戦・敗者復活戦・決勝などの名前を選択・自由入力し、各日程に投稿開始・終了、投票開始・終了を記録します。日程の追加・並べ替え・削除ができます。
- **大会の結果**：個人・タッグ・チーム、チーム名・メンバー、最終結果と任意の最終順位を記録します。予選・本戦・敗者復活・決勝などの段階ごとに結果・順位・メモを追加できます。文章は自由に残せますが、優勝・入賞回数は明示した最終結果・最終順位から集計し、途中の結果や文章から推測しません。

日時が不明な項目は未入力のまま保存できます。期間を入力する場合、終了を開始より前にしません。投稿期間と投票期間は独立しており、重なることを禁止しません。投稿期間中の表示は「投稿開始≦現在時刻＜投稿終了」の会を対象とし、キャンセル済みの会を除きます。

開始・終了日時と投稿・投票の日時はISO 8601形式で保存し、画面では端末のローカル時刻で表示します。生大喜利の開催日は任意項目 `eventDate` に `YYYY-MM-DD` で保存し、時刻未定のまま記録できます。既存データにこの項目がなくても読み込めます。日付だけの情報を、午前0時の締切として扱いません。

## 思考メモ

- 種別は **回答・お題・自由**。
- タイトル、本文、任意の会への紐づけ、作成日時、更新日時を保存します。
- 回答メモは1つのお題に複数の回答案を並べます。ネット大喜利は会と日程に紐づけ、投稿期間中の日程からそのお題一覧を開けます。期限が終わってもメモ一覧に残ります。
- 自作のお題は1件ずつ登録し、使用前・使用済みを切り替えて絞り込めます。お題本体と補足メモを分けて保存します。
- 既存の本文は自動分割せず保持し、編集画面で確認できます。日程を削除してもお題と回答を残し、削除された日程への紐づけを表示します。
- 投稿期間終了後もメモは保存され、「すべてのメモ」から開けます。
- 会を削除した場合も本文を保持し、会への紐づけだけを外します。
- 主催会のお題作りは、投稿期間中の会がなくても利用できます。

## 保存と初期範囲

会とメモは端末内のJSONファイルに保存します。書き込みが完了するまでは保存成功と表示しません。破損したファイルを空データで自動的に上書きしません。

アカウント、クラウド同期、外部サイトへの自動投稿・自動取得はありません。ローカル通知は設定で許可したときだけ予約し、参加予定の開始と、各日程の投稿締切・投票締切を対象にします。時刻未定の生大喜利は設定した当日の時刻に通知します。参加済み・キャンセルは予約しません。iOSの上限に合わせ直近64件を予約し、アプリ起動・再開・保存時に更新します。AndroidはOSの省電力制御により通知時刻が前後することがあります。会の参加者は同席した人を意味し、対戦相手や勝敗としては扱いません。

## プレイヤー・設定・共有

設定の「大喜利プレイヤー一覧」で名前とフリガナを管理します。会に保存した参加者も一覧に現れ、名前を変更すると過去の参加記録にも反映します。プレイヤーの登録情報を削除しても過去の会の名前は残ります。

JSONのschemaVersionは1を維持し、players・preferences・lastBackupAtを任意項目として追加します。これらがない既存ファイルも読み込めます。バックアップはJSONをOSの共有画面から保存し、復元は確認後に全体を置き換えます。不正なファイルや書込失敗では現在のデータを保持します。

共有ページでは参加回数・順位・会場別集計のSummaryと記録一覧のPNGを作成できます。期間・会場名・戦績・同席者の表示を変更し、一覧は15件ずつページを分けます。集計対象は参加済みの会です。

## 互換性のある追加項目

既存の単一投稿・投票期間は `effectiveRounds` でID `legacy` の日程として読みます。新しい日程は `rounds` 配列に安定したIDを持ち、名前変更や並べ替えでメモや通知が別の日程に付け替わることはありません。大会の構造化結果は任意の `tournamentResult`、思考メモのお題・回答案・日程・使用状態は任意の `prompt`・`answers`・`roundId`・`used` に保存します。既存JSONとバックアップを読み込み、従来の `resultText`・`placement`・`body` を保持します。
