# 2026-10-29の追加依頼

基準: LiveStair 8431bb5を参照し、GiriStair 0.2.1の共通UIを継承する。LiveStairは変更しない。保存JSONとメモを保持し、別ブランチのPRで確認する。

## 対応する要件

- 開発ルールをAGENTS.md/CLAUDE.mdに固定。区切り線、全画面の不要な2行表示、5分刻み、通常会→通常、文字貼り付け/OCR読み取りボタン。
- 初回に自分の名前、主催者と参加者の判定、プレイヤーのサジェスト（主催は主催頻度を優先）。
- 通常のネット大喜利は継続サイト＋今週/来週等の周期で管理。週次曜日/不定期、投稿/投票期間、所属部/お題ブロックを記録し、一覧から参加・お題を入力。
- 投稿開始から未入力欄のみ投稿締切7日後→同時投票開始→7日後投票締切。開始の既定値は開催日の前日22時と解釈し、設定変更可能にする。手入力した日時を自動上書きしない。
- 大会はステージと同ステージの複数お題回を分ける。次ステージ追加と同ステージのお題追加を別操作にする。ブロック、個人/チーム、人数2～6/無制限、自チーム・他チーム名とメンバー。
- 詳細から段階別の進出/敗退、順位なしの敗退、チーム順位・個人順位、投票人数・得点・得票率を入力。自分の最終結果と途中結果を区別し、段階の通過を優勝として集計しない。
- 敗退後も投票期間・投票通知を保持。投稿参加と投票義務を別にする。終了後に開いた生大会の結果入力導線。
- 大会全体の優勝・準優勝等を自分の結果とは別に記録。プレイヤー/チームと結び、プレイヤー詳細でもその上位成績を表示。
- 一覧は参加予定→参加済の順、通常/カレント表示を保存。生/ネットを同格に表示し、期間線・サイト名を明記。カードと詳細をLiveStairへ近づけ、参加者を行で表示。
- 「カレント」は月間カレンダーモードの意味とユーザー確認済み。一覧／カレンダーはボタンで切り替え、前月・翌月の＜＞と年月移動をLiveStairに合わせる。他のページの戻る＜も共通ナビゲーションへ統一する。
- 土曜青・日曜祝日赤、祝日計算はLiveStairと同じ。
- 思考は回答作成/お題作成の切替。日程の投稿/投票期間直下で画像お題・回答案を入力。独立回答、自作お題1件ごとの使用状態も保持。
- 設定から会場一覧（都道府県・マップ）、プレイヤーの地域・アイコン・X・メモ。アイコンはauto/show/hide、autoは1人でも設定されていれば表示。
- Giri Summary/Giri Listと集計をLiveStair参照で再構成。

## データと検証

継続サイトと周期は別IDを持ち、同一週の重複作成を防ぐ。日程・ステージ・お題のIDは名前変更や順序変更で変えない。旧単一期間・旧結果・旧プロフィール・バックアップも読み込めるよう任意項目で追加する。書込失敗時は元データを維持する。

モデル・日程補完・週次計算・投票継続・得票率・優勝集計・名前変更・復元について回帰テストを行う。iPhoneで確認する外観と未実施の確認をPRに記載する。
