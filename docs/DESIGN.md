# GiriStairの共通デザイン

LiveStairの登録画面を基準に、Flutter側の共通部品を `lib/ui/stair_theme.dart`、ネイティブ風の選択操作を `lib/ui/stair_controls.dart`、下部タブを `lib/ui/stair_tab_bar.dart` にまとめています。

## 基本

- 提示されたLiveStairの画面に合わせ、既定はライト表示です。背景は `#F9F9FB`、カードの地色は白。ダーク用の共通テーマも保持します。
- iPhoneの本文はSF Pro Text、見出しはSF Pro Display、日本語はシステム書体を使います。本文・入力値は17pxの標準ウェイトを基本にします。
- 主な操作はピンク `#FF2D55`。
- メイン画面は38pxの淡色アイコンと34pxの太字見出し。
- カードは角丸20px、淡い色の背景と枠、左側に3pxのカラーライン。
- セクション見出しは28pxのアイコン背景と18pxの太字。
- 登録は大きな基本情報カードにまとめ、見出しと各行を端まで続く細い罫線で区切ります。テキストは全幅のプレースホルダー、選択行は左に17pxの灰色ラベル、右に選択値と矢印を置きます。画面が狭い場合や文字が大きい場合は縦並びにします。
- 保存は見出しの右側に置き、タイトル未入力のときは無効にします。形式や日付・時刻はCupertinoの選択メニューやホイールを使い、キャンセル時は変更しません。
- 参加者は別の青いカードで1人ずつ入力し、「参加者を追加」「履歴から選ぶ」を用意します。
- 下部は左右に余白のある半透明のカプセル型タブバー。未選択は黒いアイコン、選択中はピンクと淡い選択背景です。タブは登録・一覧・戦績・思考・設定を維持します。

## 用途の色

| 用途 | 色 |
| --- | --- |
| 登録・基本情報 | `#F0456E` |
| 一覧・ネット大喜利 | `#6980A8` |
| 会場 | `#40999C` |
| 戦績・集計 | `#C28C47` |
| 思考・メモ | `#6B9473` |
| 設定 | `#946BB8` |

参考はLiveStairの `CommonUI.swift` 内の `AppSectionAccent`、`AppCardSectionTitle`、`appTintedCard`、`MainTabTitleHeader` と、登録画面の入力行です。LiveStairで選べる暖色テーマやテーマ切替設定を追加する変更ではありません。

投稿期間の判定、メモの保持、登録・編集・削除の動作を維持します。開催日だけの記録については `docs/SPEC.md` の `eventDate` を使います。
