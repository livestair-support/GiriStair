# GiriStairの共通デザイン

LiveStairの既定のsystem表示を参考に、Flutter側の共通部品を `lib/ui/stair_theme.dart` にまとめています。

## 基本

- ライト表示の背景は `#F9F9FB`、カードの地色は白。端末がダーク表示なら黒系の背景・カードに切り替えます。
- 主な操作はピンク `#FF2D55`。
- メイン画面は38pxの淡色アイコンと34pxの太字見出し。
- カードは角丸20px、淡い色の背景と枠、左側に3pxのカラーライン。
- セクション見出しは28pxのアイコン背景と18pxの太字。
- 入力行は左側に小さめの灰色ラベル、右側に入力欄や選択値。画面が狭い場合や文字が大きい場合は縦並びにします。
- 下部は小さなアイコンとラベルのタブバー。タブは登録・一覧・戦績・思考・設定を維持します。

## 用途の色

| 用途 | 色 |
| --- | --- |
| 登録・基本情報 | `#F0456E` |
| 一覧・ネット大喜利 | `#6980A8` |
| 会場 | `#40999C` |
| 戦績・集計 | `#C28C47` |
| 思考・メモ | `#6B9473` |
| 設定 | `#946BB8` |

参考はLiveStairの `CommonUI.swift` 内の `AppSectionAccent`、`AppCardSectionTitle`、`appTintedCard`、`MainTabTitleHeader` と、登録画面の入力行です。LiveStairで選べる暖色テーマやテーマ切替設定を追加する変更ではありません。

デザインの共通化では、記録・メモの保存形式、投稿期間の判定、登録・編集・削除の動作を変更しません。
